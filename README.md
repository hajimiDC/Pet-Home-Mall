# 宠物之家商城（Pet Home Mall）· 后端

> 《AI 辅助软件开发实践》实验四「项目实战」企业级应用 —— **宠物电商 + 本地到店服务** 复合型商城后端。
> 严格依据《需求文档》v1.2（156 个接口编号）、v1.0《测试文档》（36 条用例）实现：C 端 / 商家端 / 平台端三端一体，含交易、库存、支付、退款、结算、拼团、到店预约核销与后台 RBAC。

## 1. 快速开始

> 环境要求：**Node.js ≥ 24**（使用内置 `node:sqlite`，无需安装 MySQL / JDK / Docker）。

```powershell
cd "U:\Pet Home Mall\server"
npm install            # 仅 1 个依赖：bcryptjs（密码 BCrypt 加盐）
npm start              # http://127.0.0.1:8080
npm test               # 顺序执行 8 个测试文件（每个文件独立临时数据库），期望 8/8 通过
```

- 首次启动自动建表并写入种子数据（7 个一级 / 50 个二级 / 263 个三级类目、演示账号、商品 P1/P2/P3、券 C1/C2/C3、拼团 G1、门店 M1、到店服务 T1）。
- 健康检查 `GET /api/health`；重置数据 `npm run reset`（等价 `node scripts/seed.js --force`）。
- 数据库默认 `server/data/pet_home_mall.db`，可用环境变量 `PET_DB_FILE` 指定；配置项见 `server/.env.example`。
- 其他脚本：`npm run smoke`（主链路冒烟）、`npm run perf`（接口性能采样）、`npm run routes`（导出路由清单）、`npm run coverage`（核对 156 个需求接口覆盖度）。

## 4. 核心业务规则（可判定口径）

| 规则 | 实现 |
|---|---|
| 应付金额 | 商品总计 + 运费 − 优惠券 − 活动优惠；运费 10 元、满 99 元包邮；服务端复算，忽略前端金额 |
| 优惠券 | 每单最多 1 张平台券 + 1 张店铺券；店铺券限本店；门槛/有效期/库存实时校验 |
| 库存 | 可售 = 总库存 − 锁定库存；下单锁定（条件 UPDATE 原子扣减，不超卖）、支付扣减、取消/超时回滚；全程 `stock_logs` |
| 订单超时 | 默认 15 分钟；定时任务关单、释放预占库存、写「超时回滚」流水 |
| 支付 | 仅支付宝 / 微信支付（沙箱）；回调 HMAC-SHA256 验签 + 幂等；金额以服务端为准 |
| 退款 | 退款单状态机幂等；金额 ≤ 订单实付；退货退款回滚库存；结果回写订单与售后单 |
| 售后 | 交易完成后 15 天内可申请；同一明细仅一张进行中售后单；驳回必填原因；48 小时响应时限 |
| 评价 | 商家回复一次性（不可改，可删除后重新回复）；恶意评价申诉通过后前台隐藏且不计入评分；店铺评分 = 评价平均分 |
| 拼团 | 成团 10~99 人、3 天；拼团价 ≤ 商城价；共用 SKU 库存池；未成团全额退款（含运费）并回滚库存 |
| 到店 | 到店付款 + 预约制；核销幂等，必填收款金额与付款方式；不写库存流水、不产生支付单、不进入结算 |
| 结算 | 确认收货且过 15 天售后保护期；佣金 5%（可配）；应结 = 实付 − 佣金 − 服务费 − 退款冲减；T+7 |
| 提现 | ≤ 可提现余额；单笔 ≥ 100 元；24 小时最多 3 次；收款账户需验证（加密存储 + 掩码展示） |
| 权限 | 商家端强制 `shop_id` 隔离（忽略请求传值）；平台端 RBAC 权限码校验，无权返回 403；后台静置 30 分钟自动登出 |
| 审计 | 后台写操作全部记录 `operation_logs`（只增不改）；手机号/地址脱敏；日志不含密码明文 |

## 7. 验收要点（对应《测试文档》第 8 章）

- P0 用例（主流程、资金、库存、权限安全）全部通过自动化断言；
- 并发下单不超卖、重复提交不重复下单、支付回调重复只生效一次、退款幂等；
- 金额全部服务端复算，运费门槛与优惠券规则可判定；
- 越权（跨用户 / 跨店铺 / 无权菜单）全部拦截且不泄露资源存在性；
- 操作日志只增不改，敏感字段脱敏，密码 BCrypt 不可逆；
- 关键接口实测 P95 ≤ 6.2ms、P99 ≤ 17.8ms（见测试报告第 4 节）。
